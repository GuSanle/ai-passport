# 智能工作工牌与随身任务助手 (IDEA-01)

## 1. 业务背景与用户痛点（需求层）

在现代企业数字化与协同办公中，各类低代码/无代码平台（如飞书多维表格、钉钉宜搭、自建 BPM/ERP、简道云、n8n 等）承载了核心业务运转：审批流转、会议预订、巡检报修、待办分配与工时填报。

然而，所有数字化任务在触达物理世界时，存在两大天然缺陷：
- **PC 电脑端痛点**：员工离岗（巡检、开会、车间走动、茶水间）即失联；桌面各类弹窗极易被其他窗口覆盖或静音忽略。
- **智能手机端痛点**：
  - 消息严重过载：工作通知极易淹没在微信群、社交软件和各类营销推送中。
  - 容易分心摸鱼：为了看一条工单掏出手机解锁，极易被短视频与社交消息打断工作流。
  - 特殊作业环境受限：在实验室无菌室、车间穿戴手套、手头拿满物料时，无法掏手机解锁屏幕操作。

**产品定位**：将 **FoloToy AI Passport** 打造为企业低代码平台的**“物理实体工牌与桌面随身助手”**。平时作为胸前佩戴的身份凭证与名片，工作中作为永不漏接的主动日程提醒器与待办处理手柄。

## 2. 业务流程与用户旅程（业务层）

```
┌─────────────────┐       ┌─────────────────┐       ┌─────────────────┐       ┌─────────────────┐
│ 1. 08:55 到岗打卡│       │ 2. 10:00 今日   │       │ 3. 14:25 日程   │       │ 4. 16:30 语音   │
│  与身份工牌展示 │       │   待办清单浏览  │       │   物理主动强提醒│       │   快速填报待办  │
├─────────────────┤       ├─────────────────┤       ├─────────────────┤       ├─────────────────┤
│ NFC 碰一碰考勤  │       │ 按上下键翻看    │       │ 提前 5 分钟响铃 │       │ 长按 OK 键说话: │
│ 屏幕常驻显示    │ ────► │ 个人任务，长按  │ ────► │ 屏幕强制自动点亮│ ────► │ "明天下午约测试"│
│ 姓名、工号、部门│       │ OK 直接标记完成 │       │ 弹窗显示会议室号│       │ AI 自动录入低代码│
└─────────────────┘       └─────────────────┘       └─────────────────┘       └─────────────────┘
```

1. **晨间到岗与身份展示模式**：
   - 工牌平时处于低功耗身份卡状态，优雅展示姓名、部门、职位及当前状态（如“● 办公中”）。
   - 访客或同事用手机触碰工牌背面 NFC，瞬间打开该员工在低代码系统中的对外名片主页。
2. **随身个人待办中枢**：
   - 员工按物理 `UP` / `DOWN` 键，随时翻阅低代码系统实时同步的个人待办。
   - 完成某项工作后，在工牌上长按 `OK` 键，屏幕上的复选方块 `■` 瞬间打钩变成绿色 `✓`，并实时同步回低代码数据库。
3. **会议日程主动物理强提醒**：
   - 距离下场会议开始前 5 分钟，工牌自动发出清脆提示音，屏幕强制点亮并弹出卡片：`⏰ 14:30 (5分钟后) 302会议室 战略复盘会`。
   - 员工低头即可见，按 `OK` 确认收到，彻底避免因为手机静音或未看电脑而会议迟到。
4. **即兴语音快捷录单**：
   - 巡视或走动时，员工按住 `OK` 键对着工牌说话：“帮我记录一条明天上午10点采购合同对账”。
   - 低代码平台的 AI Agent 自动抽取字段并生成任务，并在工牌屏幕反馈提示：`✓ 已创建待办`。

## 4. 关键技术与架构细节（技术实现）

### 4.1 极简人机绑定、解绑与重登流程（体验至上原则）

面向企业日常运营，方案追求**“极致方便，杜绝误操作与运维成本”**，绝不要求员工在单片机上输入任何账号密码。

```
┌─────────────────┐             ┌─────────────────┐             ┌─────────────────┐
│ AI Passport 工牌 │             │   员工个人手机   │             │   低代码服务端   │
└────────┬────────┘             └────────┬────────┘             └────────┬────────┘
         │                               │                               │
         │ 1. 首次开机 (NVS无Token)       │                               │
         │    屏幕展示动态二维码          │                               │
         │ -------------------------►    │                               │
         │                               │ 2. 手机扫码打开绑定页面        │
         │                               │    (手机已登录低代码企业SSO)   │
         │                               │ ----------------------------► │
         │                               │                               │ 3. 为该员工与该设备
         │                               │                               │    签发专属 Device-JWT
         │ 4. 设备接收 JWT 写入本地 Flash│                               │ ◄---------------------
         │ ◄-----------------------------│                               │
         │                               │                               │
         │ 5. 建立 WSS 管道 (带JWT鉴权) ──┼─────────────────────────────► │ 6. 鉴权通过，长连接打通；
         │    工牌屏幕瞬间切出员工日程卡片│                               │    下发张三名片与待办
```

1. **初次扫码绑定（3 秒完成）**：
   - 新工牌或重置后开机，屏幕直接呈现高对比度绑定二维码（背面 NFC 亦写入相同链接）。
   - 员工拿手机一扫，手机已处于企业 SSO 登录状态，页面直接提示：`【确认绑定工牌至 张三 (工号: 8021) 吗？】`。
   - 点击【确认】，低代码服务端为该设备颁发专属长效 **`Device-JWT`**。工牌接收并写入 NVS Flash，屏幕二维码消失，瞬间亮起张三的工作名片与今日任务。
2. **断网与没电重登（100% 自动无感）**：
   - 工牌关机、断网或没电关机后，重新开机自动读取 NVS 内的 `Device-JWT`。
   - 借助 TLS 会话复用在 300 毫秒内重连 WSS，**无需任何二次登录操作**，彻底杜绝员工误点“退出登录”导致的报修麻烦。
3. **换绑与流转机制**：
   - **软件换绑**：若将工牌借给李四使用，李四拿手机扫码工牌屏幕，页面识别后提示：`当前工牌归属张三，是否转移绑定给李四？`，确认后服务端注销原 Token 并下发新 JWT。
   - **硬件恢复**：长按物理 `[UP] + [DOWN]` 组合键 5 秒，设备自动清空本地 NVS，恢复初始二维码状态。

### 4.2 全双工 WSS 与 REST 选型与功耗控制
- **拒绝高频 REST 请求**：ESP32-C3 每次建立 HTTPS REST 请求均需经历 TLS 非对称加密握手，瞬时消耗 30~35 KB 堆内存，极易引发内存碎片化和 OOM。
- **WSS 长连接常驻标准**：
  - 启动阶段完成一次握手，随后长驻维持。
  - 空闲时每 30~60 秒发送一次 2 字节 Ping 心跳帧。
  - 开启 Wi-Fi **Modem-Sleep** 节能模式，平均工作电流压至 15~20 mA，标配 600~800 mAh 电池可稳定支撑全天 8~10 小时工作。

### 4.3 物理主动唤醒与通知链路
- 当低代码平台的日历定时器到期时：
  1. 低代码引擎触发 Webhook 至 BFF 网关。
  2. BFF 顺着既有 WSS 长连接下发精简 JSON 消息包（< 200 字节）。
  3. ESP32-C3 Wi-Fi 硬件中断瞬间唤醒 CPU。
  4. 固件拉高背光引脚点亮屏幕，驱动蜂鸣器鸣响，将日程数据绘制在 LCD 视口上。

## 5. 商业价值与总结（总结层）

1. **赋予低代码平台实体硬件触角**：
   - 将虚拟的云端数据流转转变为看得见、摸得着的物理实体设备，极大提升产品差异化与解决方案溢价空间。
   - 解决企业关键任务流转“最后一米”的强触达难题。
2. **极佳的免维护与员工体验**：
   - 无退出登录误操作陷阱，免去繁琐运维支撑。
   - 扫码一键绑、碰一碰考勤名片，员工零学习成本。
3. **硬件综合成本极具竞争力**：
   - 基于 ESP32-C3 极简无外扩 PSRAM 方案，配合仓库内置的 837 KB 高压缩矢量汉字库，以百元级极致硬件 BOM 成本实现千元级专业级智能工牌的视觉质感与双向语音交互。
