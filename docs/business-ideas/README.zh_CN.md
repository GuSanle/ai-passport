## 业务场景方案规范模板

所有收录的场景方案均严格遵循以下五维标准结构进行组织：

1. **业务背景与用户痛点（需求层）**：现实业务瓶颈、手机/PC 触达痛点与立项必要性。
2. **业务流程与用户旅程（业务层）**：从员工、管理者、系统三方视角的端到端交互流转。
3. **软硬协同产品设计（设计层）**：屏幕界面布局、物理按键交互模型、云端低代码与硬件分工边界。
4. **关键技术与架构细节（问题与技术层）**：低功耗休眠（Modem-Sleep / RTC）、通信协议（WSS 长连接）、人机绑定/换绑机制（JWT、动态二维码、NFC）、硬件红线（零 PSRAM、Flash 字库映射）。
5. **商业价值与总结（总结层）**：差异化核心优势、降本增效指标与运营落地建议。
